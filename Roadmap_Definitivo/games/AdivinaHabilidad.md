# Pokebeck Hub - Adivina la Habilidad

**Versión:** 1.0

---

# 1. Descripción

Adivina la Habilidad es un juego donde el jugador debe identificar una habilidad Pokémon a partir de la descripción de su efecto.

El objetivo es comprender cómo funcionan las habilidades y aprender qué Pokémon pueden utilizarlas.

---

# 2. Objetivo del Juego

Identificar correctamente la habilidad descrita.

El juego busca enseñar mecánicas importantes del universo Pokémon, especialmente aquellas relacionadas con el combate.

---

# 3. Habilidad que Entrena

* Comprensión.
* Asociación.
* Conocimiento competitivo.
* Memoria.

---

# 4. ¿Qué aprende el jugador?

* Funcionamiento de las habilidades.
* Utilidad de cada habilidad.
* Pokémon que pueden poseerlas.

---

# 5. Mecánica Principal

El juego muestra la descripción de una habilidad.

El jugador debe escribir el nombre correcto utilizando el sistema de búsqueda con sugerencias.

---

# 6. Sistema de Respuesta

La respuesta se realiza mediante escritura.

El sistema ofrecerá sugerencias/autocompletado para facilitar nombres largos o complejos.

Las sugerencias no revelan automáticamente la respuesta.

---

# 7. Dificultades

## Fácil

* Habilidades muy conocidas.
* Descripciones sencillas.

## Moderado

* Habilidades menos frecuentes.
* Efectos más específicos.

## Difícil

* Habilidades raras.
* Efectos similares entre varias habilidades.
* Mayor necesidad de comprensión.

---

# 8. Información Posterior

Después de responder, el jugador visualizará una ficha educativa.

La ficha incluirá:

* Nombre de la habilidad.
* Descripción.
* Explicación sencilla.
* Pokémon destacados que pueden poseerla.

Esta información tiene como objetivo reforzar el aprendizaje independientemente del resultado de la partida.

---

# 9. Temporizador

No utiliza temporizador.

El jugador debe poder leer cuidadosamente cada descripción.

---

# 10. Sistema de Fallo

Regla global de Pokebeck Hub.

Una respuesta incorrecta finaliza la partida.

No existen vidas.

---

# 11. Sistema HX

El juego utiliza el HX global.

La recompensa dependerá del rendimiento del jugador.

La fórmula definitiva será definida posteriormente.

---

# 12. Récords

Ejemplos:

* Mejor racha.
* Mayor cantidad de respuestas correctas.
* Mejor puntuación.

Los récords no afectan el HX.

---

# 13. Internacionalización

La estructura de datos deberá permitir múltiples idiomas.

Versión inicial:

* Español.

Versiones futuras:

* Inglés.
* Japonés.

---

# 14. Duración Objetivo

Las partidas deben durar entre 2 y 4 minutos.

---

# 15. Identidad del Juego

Pregunta principal:

> ¿Reconoces esta habilidad por su efecto?

Personalidad:

* Comprensión.
* Aprendizaje.
* Conocimiento competitivo.
